\section{Experimental protocol}\label{sec:protocol}

\paragraph{Data.} We use the X3-repaired inference cache of the original study~\citep{das2026aip}: greedy answers of nine open-weight models on six benchmarks. The benchmarks are MMLU~\citep{hendrycks2021mmlu}, MedQA~\citep{jin2021medqa} and ARC~\citep{clark2018arc} (four options each), BoolQ~\citep{clark2019boolq} (binary), and GSM8K~\citep{cobbe2021gsm8k} and MATH-500~\citep{hendrycks2021math,lightman2023verify} (open answers). That is 200 questions per benchmark and 500 for GSM8K. The frozen roster has seven models from seven labs, ranging from 44.5\% (Llama-3.2-3B) to 94.0\% (Gemma-4-31B) on MATH-500. The cache also contains answers that Llama-3.2-3B and Ministral-3-14B wrote under four deception prompts. Before the repair, 944 of 13{,}500 rows were answers ``manufactured'' by the extractor from truncated generations (35\% of MATH-500 rows). All earlier MATH-500 conclusions are therefore superseded (\cref{sec:audit}).

\paragraph{Worlds.} A world has a benchmark, a Byzantine fraction $f$, an attack, a visibility $p_{\text{obs}}$ and a seed. It contains $N=10$ identities. Each honest identity replays one cached model, round-robin over a shuffled roster, so some models repeat. Byzantine identities are a prefix of one fixed permutation, which nests the corrupted sets across $f$. Questions are split by a stable hash into disjoint HISTORY / VALIDATION / TEST partitions (40/20/40\%). Every receiver fits on HISTORY only and is scored on TEST. VALIDATION is used only to select attacks for the best-response analysis. The defence input is stripped of gold, Byzantine flags, model names and attack labels.

\paragraph{Open answers.} Two answers on the same question are merged when the repository's equivalence checker (symbolic \texttt{math\_match} for MATH-500, numeric equality for GSM8K) says they denote the same value. This compares answers with \emph{each other}, never with the key, so a deployed receiver can do the same. It is applied identically to every method.

\paragraph{Methods.} \emph{Deployable:} receiver alone; majority vote; logprob confidence weighting; SAC filter-refine; \aip\ gated, trust-only, naive and soft-gate (M1); one-coin label-free Dawid--Skene (plurality-initialised, the unanchored ablation of \race); full Dawid--Skene~\citep{dawid1979}; and \race\ with its variants (full confusion, self-cap, and three superseded variants kept as ablations). \emph{Oracles} (upper references, not deployable): majority over the honest agents a receiver heard, and a known-channel decoder that uses \race's scoring rule with accuracies measured against gold on HISTORY. All \aip\ variants use the published calibrated ceilings and the fixed code of~\citep{nabidnur2026bucket}.

\paragraph{Studies.}
\begin{itemize}
\item \textbf{E1 (main):} $f\in\{0,.1,\dots,.9\}$, coherent liars, $p_{\text{obs}}\in\{1,.5\}$, 5 seeds; 600 worlds.
\item \textbf{E2 (attack zoo):} 14 symbolic attack settings at $f\in\{.3,.5,.7\}$, 3 seeds; 756 worlds.
\item \textbf{E3 (replayed LLM deceivers, confirmation set):} 4 prompts, $f\in\{.1,.3,.5,.7\}$, 5 seeds; 480 worlds.
\item \textbf{E4 (composition, replication, swarm size).}
\item \textbf{E5 (history length).}
\item \textbf{E6 (online, predict-then-commit, under changing attackers).}
\item \textbf{E7 (channel-estimation diagnostics).}
\item \textbf{E8 (live six-model swarm, confirmation set).}
\end{itemize}

\paragraph{Statistics.} Receivers, seeds and peers within a world reuse the same cached answers, so they are not independent samples. We average accuracy over honest receivers and seeds within each question. We then compare methods on the same questions, using a paired percentile bootstrap (2{,}000 resamples) for 95\% intervals and a Wilcoxon signed-rank test for $p$-values. Within each study, $p$-values are Holm-corrected~\citep{holm1979} over all cells and baselines. A verdict is ``win''/``loss'' only if the corrected $p<0.05$ \emph{and} the bootstrap interval of the mean difference excludes zero; the two criteria disagree in none of the per-benchmark cells of E1--E3, but they can when cells pool heterogeneous benchmarks.

\paragraph{Compute.} Everything except E8 replays cached answers on a 4-core CPU without a GPU. E8 runs fresh inference with six 1--2B-parameter models on the same CPU. Wall time and peak memory are recorded in each study's manifest.
