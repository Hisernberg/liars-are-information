Liars are information

When some agents in a multi-agent LLM system lie, honest agents can still use what the liars say, as long as the lies depend on the truth. An agent that never tells the truth rules out one answer every time it speaks. RACE (Receiver-Anchored Channel Estimation) learns this from each honest agent's own unlabeled history, anchored on the one fact the agent knows: that it is itself honest.

The film: how the swarm works

Ten agents on MMLU, five of them real LLMs prompted to mislead after seeing the honest answers. (1) Every agent answers, broadcasts, and each honest agent decides with its own learned trust links. (2) The swarm's trust matrix learning over 90 unlabeled questions. (3) One question in slow motion: counting votes vs. weighing evidence. (4) Results.
